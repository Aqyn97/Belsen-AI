02 / Under the surface

Built around
data integrity.

One Java modular monolith. One authenticated application origin. PostgreSQL as the source of truth.

  1. Public showcaseCloudflare PagesStatic HTML + CSS · Free
  2. Proposed application hostOracle ARMJava 21 + Spring Boot + React · Eligibility pending
  3. Persistent dataPostgreSQL 17Private Docker network · Proposed on the ARM VM

The static showcase is the first release target. Oracle full-stack hosting is proposed, subject to eligibility and capacity. Application traffic will stay on one HTTPS origin. No public deployment is claimed.

Secure by default

Server-side JDBC sessions. Secure, HttpOnly cookies. CSRF protection. Owner-scoped queries and versioned writes. Public signup and optional providers are disabled for the proposed preview.

History over guesswork

Flyway migrations and Hibernate validation. Append-only task and habit records. Idempotent progress submissions. One repeatable-read snapshot per dashboard response.

Evidence before advice

The optional AI Coach can rank only Java-defined actions from a bounded evidence preview. AI cannot change records or calculate authoritative metrics. Live Groq inference remains disabled and unverified.

Tested across boundaries

PostgreSQL Testcontainers, React component tests, real-backend Chromium journeys, packaged HTTPS checks and automated accessibility scans. Exact evidence lives in the repository.
